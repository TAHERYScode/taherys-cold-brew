# TAHERYS Cold Brew — Beta App

Customer bottle/QR experience + admin inventory & order dashboard, built with React + Vite.

## Run it locally

```
npm install
npm run dev
```

Then open the local URL it prints (usually http://localhost:5173).

## Deploy

Push this whole folder to a GitHub repo, then on vercel.com click
"Add New" → "Project" → select the repo. Vercel auto-detects Vite
and deploys it — no config needed.
